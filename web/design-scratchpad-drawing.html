Somebody is drawing. Show it.

Six ways to signal a live turn without touching the canvas bitmap. Everything below is CSS and inline SVG on the existing tokens — no library, no new asset, nothing that reads or renders a word. Each specimen is running at its real speed.

Six specimens

Read the chips: where it lives in the app, and what it costs to build.

AThe paintress

A beret-wearing artist perched on the paper's edge, dabbing in the artist's own pen ink. Marker colour is bound to the live palette index, so the sprite recolours itself when the artist switches pens.

stage ledge, outside the bitmap ~70 lines SVG + 4 keyframes has a face, reads instantly
BMarker in hand

No character — a cuffed hand and a fat marker sweeping across the sheet, laying down a stroke that draws itself and lifts. Same read as A, half the personality, none of the cartoon risk if you ever want the game to feel grown-up.

stage margin or phase header ~25 lines SVG theme-neutral
CInk ghost

A phantom stroke that draws in the artist's ink at low opacity, then evaporates. Two paths, one keyframe, pathLength="1" so nothing needs measuring. Cheapest thing on this page and the only one that stays calm for a full six-round match.

watermark behind an empty canvas ~8 lines CSS could be mistaken for a real stroke
DMarginalia

Idle doodles that draw themselves in the paper margin, one at a time, then clear. Fills the dead first eight seconds of a turn when the canvas is still blank — which is exactly when watchers are most likely to wonder if the app froze.

margin strip, never inside the canvas one path per doodle busy if it runs all turn
ELive marker rack

Nothing new on screen: the twelve pens you already render start breathing, and the selected one lifts out of the rack with its cap bobbing. The cheapest way to make the whole screen feel alive, and it doubles as feedback for which pen is armed.

web/src/ui/tools.ts CSS only, no markup change zero new elements

What I'd ship

And the two things that would go wrong if you shipped all six.

A + E + F

The paintress on the stage ledge for character, the marker rack alive because it's free, and the baton pass on turn change because it's the only one that carries information.

Skip C and D once A is in — three ambient loops on one screen is noise, and A already answers the question they answer.

Keep motion off the bitmap

Anything animated inside the canvas rect can be misread as a stroke Rin drew — which actively hurts a deduction game where players are reading marks for intent.

So the sprite sits on the frame, in the margin, or in the chrome. Never composited over the shared drawing.

Tempo can follow the clock

One custom property — --dab:1.9s on the sprite, driven from the same deadline the timer already reads. Under ten seconds she goes frantic.

Free urgency, no new state, and it makes the character mean something instead of just idling.

Invariant-safe by construction

None of this reads state.word or any peer's word. It's driven by artistId, turnIndex, palette index and deadline — all already on every client.

The canary test is untouched. prefers-reduced-motion is honoured at the top of the stylesheet, matching web/src/styles/base.css:130.
